# Upgrading

## XP version requirement

> **Important:** Content Studio 5.x requires XP 7.13.0 or newer.

### Default Content Project

Default Content Project is no longer available in Content Studio by default.

If you need the Default project, enable it via Content Studio’s [config file](docs/content-studio/5.x/config.md#enable_default_content_project) before upgrading to Content Studio 5.
