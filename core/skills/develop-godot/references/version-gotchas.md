# Version gotchas (4.x to 4.7)

Checked against the 4.7 offline catalog on 2026-10-30. Items marked UNVERIFIED were not found in it. Upgrade guides: `tutorials/migrating/upgrading_to_godot_4.{3,4,5,6,7}.md`.

| Since | Do | Do not |
|---|---|---|
| 4.3 | One `TileMapLayer` node per layer, with a shared `TileSet`. | Use `TileMap` (deprecated). |
| 4.5 | `TileMapLayer` physics chunks cells by `physics_quadrant_size`. Set it to 1 for per-tile bodies or old behavior. | Assume per-cell bodies from 4.5 on. |
| 4.x | `Parallax2D` for scrolling backgrounds. | Use `ParallaxBackground` (deprecated). |
| 4.6 | The editor writes Jolt into newly created projects (`upgrading_to_godot_4.6.md`), but `classes/class_projectsettings.md` says `DEFAULT` equals GodotPhysics3D. When writing `project.godot` by hand set `physics/3d/physics_engine="Jolt Physics"` (the `[physics]` key is `3d/physics_engine`, as in the 3d-character example). | Rely on `DEFAULT` or assume the engine. |
| 4.5 | With Jolt, `Area3D` always reports overlaps with static bodies (the `areas_detect_static_bodies` setting was removed). Ignore them via collision layer or mask (`upgrading_to_godot_4.5.md`). | Expect Godot Physics static-overlap behavior. |
| all 4.x | `move_and_slide() -> bool`; velocity in units per second; call from `_physics_process`. | Multiply velocity by `delta` before `move_and_slide()` (that is for `move_and_collide`). |
| 4.4 | Typed `Dictionary[K, V]`. | Leave dictionaries untyped in new code. |
| 4.4 | `.uid` files are generated by the editor or `--import`. Commit them with their resource (upstream convention; UNVERIFIED in the catalog). | Hand-author or delete them. |
| 4.4 | `@export_file` stores `uid://` paths when set in the Inspector. Since 4.5 use `@export_file_path` for raw `res://` strings (`upgrading_to_godot_4.4.md`). | Parse an `@export_file` value as a plain path. |
| 4.4+ | `@export_tool_button` needs `@tool` on the script. | Use it in a runtime-only script. |
| 4.x | `AnimationMixer` is the base of `AnimationPlayer` and `AnimationTree`. `AnimationPlayer.current_animation`, `assigned_animation`, `autoplay` are `StringName`. | Compare them with `String` using `is` or type-check as `String`. |
| 4.5 | `Resource.duplicate(true)` copies only internal sub-resources. Use `duplicate_deep()` for a full independent copy. | Expect `duplicate(true)` to clone external resources. |
| 4.6 | Scene files no longer write `load_steps`. Expect diffs where it vanishes. | Add it by hand. |
| 4.6 | Glow defaults changed (default blend mode Screen). Re-tune glow after upgrading. | Assume old glow looks identical. |
| 4.6 | New Windows projects default to Direct3D 12 (`rendering/rendering_device/driver.windows`). | Assume Vulkan on Windows. |
| 4.5 | GDScript `@abstract` and variadic `...args`. | Use them in a project below 4.5. |
| all 4.x | `load()` blocks; async is `ResourceLoader.load_threaded_request`. | Treat `load()` as asynchronous. |
| 4.4 | Physics interpolation: enable `physics/common/physics_interpolation`; call `reset_physics_interpolation()` after teleporting a node. Docs: `tutorials/physics/interpolation/`. | Move an interpolated node's transform without resetting after a teleport. |
| 4.7 | `AreaLight3D` (`classes/class_arealight3d.md`) and HDR output (`tutorials/rendering/hdr_output.md`) are in the catalog. Control offset transforms and the Asset Store: UNVERIFIED in the catalog. | Guess property names for new 4.7 features. |

## Headless CLI

Flags confirmed in `tutorials/editor/command_line_tutorial.md`: `--headless`, `--path`, `--script`/`-s`, `--check-only`, `--import`, `--quit`, `--quit-after`, `--export-release`, `--export-debug`, `--doctool`, `--gdscript-docs`. An unknown flag fails silently: confirm with the exit code and output, not the absence of errors.
