# Release Notes

The Enonic CMS stack is composed of several independent products, each released and versioned on its own cadence. Every product on [Enonic Market](https://market.enonic.com) has a **Releases** section listing its versions and changes — that’s the canonical source for what’s new.

A few components also publish more detailed release notes in their own documentation:

- [Enonic XP 8](docs/platform/stable/release.md) — the platform core that hosts the CMS.

- [Content Studio](https://market.enonic.com/vendors/enonic/content-studio) — primary authoring interface.

- [Headless API (Guillotine)](https://market.enonic.com/vendors/enonic/guillotine) — GraphQL API for headless delivery.

Subscription components:

- [Content Studio+](https://market.enonic.com/vendors/enonic/content-studio-plus) — advanced editorial features.

- [AI Content Operator](https://market.enonic.com/vendors/enonic/ai-content-operator) — AI-assisted authoring.

Other Enonic-published and third-party apps — SEO tools, analytics, importers, and more — are listed on [Enonic Market](https://market.enonic.com).
