# Content Editor

The **Content Editor** opens in a new browser tab from the [Navigator](docs/content-studio/stable/workbench/navigator.md) when content is created or edited. Multiple content tabs can be open at the same time. Clicking on the **Content Studio** tree icon in the top left corner will open the [Navigator](docs/content-studio/stable/workbench/navigator.md) in a new browser tab. User will get a browser warning upon trying to close a tab with modified but unsaved content.

The edit view has three panels. On the left is the [Content Form](docs/content-studio/stable/editor/content-form.md), where the content’s data fields are edited. In the middle is either the [Page editor](docs/content-studio/stable/editor/page-editor.md) (for renderable content — a drag-and-drop page-building surface) or the [Preview](docs/content-studio/stable/workbench/preview.md) panel (for other content types — a type-appropriate read-only preview). On the right is the [Context panel](docs/content-studio/stable/workbench/contextpanel.md), which hosts built-in widgets (Details, Version history, Dependencies, and — for renderable content — Components) as well as any widgets contributed by installed applications.

## Collaboration

Toolbar of the Content Editor will display avatar icons of users who currently have the same content opened in the Content Editor.
