# React4XP 6 reference documentation

Server side React rendering for Enonic XP applications.

> **Tip:** **New to React4XP?** Visit our [React4XP tutorial](https://developer.enonic.com/learn/react4xp-tutorial) for a hands-on, guided introduction.

## Introduction

React4XP lets front-end developers build **Enonic XP applications with React**. React components are rendered [server-side](docs/react4xp/6.x/ssr.md) and then [hydrated](docs/react4xp/6.x/ssr.md#hydration) in the browser by default, so the same React code runs on both the server and the client (isomorphic rendering).

> **Note:** This documentation covers **React4XP 6.x**, which builds on **React 19** and requires **Enonic XP 7.16** or later. For the current version, switch to the **7.x** docs.

## How React4XP is distributed

React4XP comes in two parts:

Library (lib-react4xp)

The Enonic XP library that does the rendering. It exposes the `render`, `processHtml`, `assetUrl` and `serviceUrl` functions, the `DataFetcher` class and the `React4xp` object - all documented in the [Library reference](docs/react4xp/6.x/library.md). Available on [Enonic Market](https://market.enonic.com/vendors/enonic/react4xp-lib) and [GitHub](https://github.com/enonic/lib-react4xp). Your React sources are compiled by the companion npm build tool `@enonic/react4xp` ([npm](https://www.npmjs.com/package/@enonic/react4xp)).

Starter (starter-react4xp)

A ready-to-run project that bundles the library, the `@enonic/react4xp` build integration, and a Hello world setup - so `enonic project create` gives you a working React4XP setup in one step. Documented in the [Starter reference](docs/react4xp/6.x/starter.md); available on [Enonic Market](https://market.enonic.com/starters/react4xp-starter) and [GitHub](https://github.com/enonic/starter-react4xp).

A fully working demo application is available on [Enonic Market](https://market.enonic.com/vendors/enonic/react4xp-demo).
