# Development and the SDK

> **Important:** For hands on introduction to development and the SDK, visit the [quickstart](https://developer.enonic.com/start), [Developer 101](https://developer.enonic.com/docs/developer-101), or [My first site](https://developer.enonic.com/docs/my-first-site) tutorials.

## Introduction

The majority of functionality and customizations in Enonic XP is implemented and delivered via [applications](/docs/platform/7.x/apps). Application development mainly relates to defining customer specific [schemas and content models](/docs/platform/7.x/cms) as well as coding based on [Enonic’s JavaScript Framework](/docs/platform/7.x/framework)

To facilitate and ease development, Enonic provides a purpose-specific SDK, libraries, starters and other tools to assist developers in their work.

## SDK

The Enonic SDK consists of several independent tools:

- [Enonic CLI](https://github.com/enonic/cli-enonic)

- SDK versions of the [Enonic XP distro](/docs/platform/7.x/deployment/distro)

- [Sandboxes](/docs/platform/7.x/development/sandboxes)

- [Build system](/docs/platform/7.x/development/build)

- [Starters](https://market.enonic.com/starters)

- [Platform libraries and APIs](/docs/platform/7.x/api)

- [Other libraries](https://market.enonic.com/libraries)

The CLI plays a central role in orhchestrating development activities, including downloading distros, setting up new development projects, building and even deploying to productin servers.
