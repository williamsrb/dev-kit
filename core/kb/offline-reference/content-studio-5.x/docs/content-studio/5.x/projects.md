# Content Projects

Content Studio allows you to organize your content in multiple independent repositories aka Projects.

Content Projects also offer individual access control and permissions, as well as other settings to toggle features and language(s) for the project.

Privileged users can create and manage projects via [Content Studio settings](docs/content-studio/5.x/settings.md).

## First project

For new Enonic installations, you will have to [create an project](docs/content-studio/5.x/settings.md#new_project_wizard) to get started.

## Project selector

If you have access to multiple projects, you can easily swich to a different project in the context selector

## Project layering

Content Studio also offers an advanced feature for reusing and augmenting content across multiple projects. This is called [content layering](docs/content-studio/5.x/layers.md).
