## Built like an operating system

XP is a self-contained platform with an ecosystem of applications that run on top.

Based on original illustration from [Unity Vectors by Vecteezy](https://www.vecteezy.com/free-vector/unity)

## Apps

Standalone software packages that can be installed and started on Enonic XP with access to all platform services and APIs. Use them to add specific features and functionality to your instance, ranging from APIs to administrative interfaces.

> **Tip:** **Building your own apps?** Visit [Enonic Development Kit](https://developer.enonic.com/docs/code) documentation.

> **Tip:** **Visit [Enonic Market](https://market.enonic.com)** for official apps from Enonic, and 3rd party developers.

## Platform

The platform provides essential services and APIs that applications leverage to build their functionality.

- [Endpoints](docs/platform/stable/endpoints.md) - HTTP entry points for 3rd party client interactions.

- [App runtime](docs/platform/stable/apps.md) - Able to power and run multiple applications simultaneously.

- [Identity and Access Management (IAM)](docs/platform/stable/security.md) - A comprehensive security model for authentication and authorization across the platform.

- Clustering - for distributed memory caching, events and job execution.

- [NoSQL storage](docs/platform/stable/storage.md) - A built-in NoSQL storage engine for storing content, application- and system data.
