# Tooling

## Introduction

Enonic’s Development Kit consists of several independent tools:

- [Enonic CLI](https://github.com/enonic/cli-enonic)

- SDK versions of the [Enonic XP distro](https://developer.enonic.com/docs/platform)

- [Sandboxes](docs/code/stable/tooling/sandboxes.md)

- [Build system](docs/code/stable/tooling/build.md)

- [Starters](https://market.enonic.com/starters)

- [System libraries and APIs](docs/code/stable/libraries.md)

- [Other libraries](https://market.enonic.com/libraries)

Enonic CLI plays a central role in orhchestrating development activities, including downloading distros, setting up new development projects, building and even deploying to production servers.
