# StandardMaterial3D

**Inherits:** [BaseMaterial3D](class_basematerial3d.md) **<** Material **<** [Resource](class_resource.md) **<** RefCounted **<** Object

A PBR (Physically Based Rendering) material to be used on 3D objects.

## Description

**StandardMaterial3D**'s properties are inherited from [BaseMaterial3D](class_basematerial3d.md). **StandardMaterial3D** uses separate textures for ambient occlusion, roughness and metallic maps. To use a single ORM map for all 3 textures, use an ORMMaterial3D instead.
